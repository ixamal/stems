# stems

David’s NUO-STEMS shop on `ix`. I point, the agent heavy-lifts, we meet in the notes. [ixamal](https://github.com/ixamal) / [alkalurops.org](https://www.alkalurops.org).

Grab tracks → NUO-STEMS 4 → native Traktor Pro 4 stems. Same machine as Traktor. Audio stays on disk. This repo is the log + how we clicked it.

**First click (that welcome screen):** **Traktor Pro 4 Native**. Hit Understand. That’s the one NI’s Generate Stems button would have made. You are not on a second PC.

| Mode | When |
|------|------|
| **Traktor Pro 4 Native** | This Mac. Links stems into the Traktor 4 collection. Start here. |
| Legacy / Export | Only if you render on a *different* computer, then Traktor Utilities on the DJ laptop. |
| DAW / Non-Traktor | WAV/FLAC splits. Later, if Maschine wants files instead of a Traktor STEM. Not tonight. |

Demo Mode is fine to prove one track. License when the pipe is real.

Library paths and old organize scripts live in [ixamal/music_migration](https://github.com/ixamal/music_migration) (`~/Music/stems_audio`). The mixer cable is [ixamal/blackhole](https://github.com/ixamal/blackhole). Don’t mix those fights into this chat.
